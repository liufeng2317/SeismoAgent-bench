# Documentation source manifest

The transformed GaMMA examples and Agent-oriented summaries were copied from:

`TRACE-1.1/seismoagent/library/RAG_Script/Retrieve_package_example_RAG/Transformed_Example_Md/gamma/v4`

The five curated Agent usage guides in `core/` are consolidated from the
corresponding `*_core_usage_summary`, `*_file_summary`, `*_config_summary` and
`*_plotting_usage_summary` files. Older transformed copies (`v1`–`v3`) are not
duplicated. Whitespace-only formatting was normalized in copied text files;
executable content and parameters were not otherwise rewritten.

The raw transformed examples, generated implementation pages, upstream
tests/notebooks, retrieval descriptions and supporting figures were intentionally
removed from this runtime repository. The runnable examples under `examples/`
are the maintained validation entry points. They remain methodological
references and do not add case observations or reference catalog outputs to the
tool package.
