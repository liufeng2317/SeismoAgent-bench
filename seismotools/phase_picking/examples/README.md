# Validated phase-picking examples

The Python files in this directory are the validated model-usage examples for the bundled phase-picking implementations. Read the relevant model example before adapting an inference workflow. Usage guidance is in [`../docs/examples/README.md`](../docs/examples/README.md).

The `smoke/` directory contains a minimal check of the stable local interface. It is only an interface test; it does not replace the model examples or create an event catalog.
