# Phase-picking examples

The Python files and notebook in this directory are reference inference
examples for the bundled model implementations. They are useful for checking
model-specific APIs and preprocessing conventions; they do not replace the
stable interfaces in `../../interface/` and do not create an event catalog.

Use `../../examples/smoke/run.sh` for a minimal interface check. The same
validated Python examples are copied into `../../examples/` for direct use.
