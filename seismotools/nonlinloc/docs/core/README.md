# NonLinLoc core guides

The core guides describe the standard 1-D workflow and the local Nonlinlocpy
helpers:

- `run_nonlinloc_standard_example_*` documents the prepared standard workflow;
- `run_nonlinloc_example_*` documents the lower-level example workflow;
- use the file and plotting summaries after reading the corresponding core and
  configuration summaries.

The stable command-line boundary is documented in `../../interface/`. The
Python package and native control syntax are documented in
`../../runtime/python/Nonlinlocpy/`. Case observations and reference catalogs
are outside this tool directory.
