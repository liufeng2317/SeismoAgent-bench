# hypoDD core guides

Use these guides by relocation mode:

- `CASE_CATALOG_ONLY_*` describes catalog differential-time (CT) relocation.
- `CASE_CROSS_CORRELATION_*` describes catalog plus waveform cross-correlation
  (CT+CC) relocation.
- `CASE_CC_ONLY_*` describes CC-only relocation.
- `AGENT_CONTRACT_CARD.md` summarizes the common input, output and validation
  boundary.

Read the mode's core and configuration summaries first. Use the file and
plotting summaries only when the selected workflow needs those details. These
are generic method guides; case-specific observations and reference catalogs
must remain outside the tool package.
