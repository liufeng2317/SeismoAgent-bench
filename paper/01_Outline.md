# 论文大纲

暂定题目：**Agent 能自动构建可信的地震目录吗？——工具、知识与自我检验各起多大作用**

当前结果见 [02_Current_Results.md](02_Current_Results.md)。本文只写论文的问题、论点、证据和结构；实验过程和决策记录见 [docs/research/02_Paper_Outline.md](../docs/research/02_Paper_Outline.md) 及其链接的文档。

## 1. 核心问题

> **Agent 方法能否自动构建高精度地震目录？如果不能，缺的是工具、知识，还是检验自身结果的能力？**

地震目录构建是一个完整的科学工作流（拾取、关联、模板匹配检测、定位、相对定位、震级），每一步都可以和独立的参考目录客观比较，因此适合衡量 Agent 做科学研究的能力。

## 2. 贡献

1. **分级基准。** 六个从基础到困难的案例，覆盖诱发地震、震群、火山、中强和大型主震–余震序列、复杂多断层环境；每个案例有多个独立参考目录，并有一份 human-in-loop 最终目录作为上限。
2. **评估方法。** 不用单一汇总分，而是按维度给出"可信目录"判定（事件真实性、时间、空间、震级），完整性单列；把整体偏移和离散分开。
3. **阶梯实验。** 同一个通用 Agent，每一级只多给一个因素：工具（S1）→ 自动检验（S2c）→ 知识加自动检验（S3），由此分离各因素的贡献。
4. **不依赖参考目录的检验及其边界。** 把专家经验写成确定性的 checker 和 Agent Skill；说明它能挡住哪些错误，以及哪些误差只靠 Agent 自己的数据无法判断。

## 3. 实验设计

### 3.1 案例

| 分级 | 案例 | 类型 | 台站 | 时段 | 主要难点 |
|---|---|---|---:|---|---|
| 基础 | Prague 2011 | 诱发地震，Mw 5.7 余震 | 23 | 8 天 | 台网紧凑；台站部署变化 |
| 基础 | Magna 2020 | 中强主震–余震，Mw 5.7 | 47 | 8 天 | 盆地速度结构；深度约束 |
| 中等 | Maple Creek 2017 | 黄石震群，最大 Mw 4.4 | 27 | 8 天 | 只有垂直分量的台站；小事件密集；大事件震级 |
| 中等 | Kīlauea 2018 | 火山口塌陷，Mw 6.9 | 25 | 8 天 | 三维结构；Mw 6.9 尾波 |
| 困难 | Ridgecrest 2019 | M6.4 与 M7.1 序列 | 42 | 3 天 | 主震尾波；关联密度极高；大事件质控 |
| 困难 | Kaikōura 2016 | Mw 7.8 多断层余震 | 53 | 8 天 | 260 km 台网；三维结构；一维与三维框架偏移 |

### 3.2 Agent 阶段

原则：Agent、模型、循环和输出合同都不改，每一级只往 Agent 的环境里加文件。所有阶段都是"只给原始波形、不给参考目录"的条件。当前模型为 Claude Code × GLM-5.3。

| 阶段 | 配置 | 比上一级多给 | 回答的问题 |
|---|---|---|---|
| S0 | `min` | 任务、数据、输出合同 | 通用 Agent 自己能否做出可信目录？ |
| S1 | `tools` | 经过验证的工具库 `seismotools` 及说明 | 工具带来什么？ |
| S2c | `checker` | 工具 + 不依赖参考目录的 checker（只报症状，不给原因和修复） | 知道"哪里不对"能否让 Agent 找到并修好？ |
| S3 | `knowledge_checker` | 工具 + checker + 与案例无关的专家知识（Agent Skill） | 知识加自动检验能否弥合与专家的差距？ |
| 上限 | human-in-loop 最终目录 | — | 唯一的比较基准 |

checker 是确定性程序，规则不含案例数值、不读参考目录；Agent 需要对每条报警给出处置（已修复，或给出理由），评分端重跑 checker 核对。知识以 Agent Skill 的形式提供，内容包括流程与方法选择、安全参数范围、已知陷阱，以及"症状 → 可能原因 → 上游修复"对照表；不提供任何具体速度模型。

### 3.3 评估

- **基准**：human-in-loop 最终目录是唯一的比较对象和上限；参考目录用于检测召回和震级。
- **指标**：序列尺度的匹配门限、偶然匹配校正、与最终目录直接比较。
- **可信目录判定**：四个维度（事件真实性、时间、空间、震级），每个维度看准确性（相对最终目录的偏移）和稳定性（离散与一致性）；完整性单列。
- **主要度量**：不通过的可信标准数；各维度的差距弥合率 (S_k − S1) / (final − S1)，针对归一化召回、水平偏移、深度偏差、震级偏差，按分级报告。
- **辅助分析**：组件替换（Agent 前端 + 专家后端，反之亦然）；专家阶梯；盲审。

## 5. 章节安排

1. **引言**：Agent 驱动的科学研究；为什么地震目录是一个完整、可客观检验的任务；核心问题与贡献。
2. **相关工作**：科学 Agent 基准；自我检验与批评（CRITIC 等）；地震目录自动化流程与质控文献。
3. **基准（论点 1）**：六个分级案例；参考目录与互相召回上限；human-in-loop 最终目录的构建及其精度说明（模板匹配事件落在网格上，相对位置精度不如互相关重定位目录）。
4. **评估方法（论点 1）**：指标 v2；偏移与离散分解；可信目录判定；组件替换；v1 → v2 的教训。
5. **结果一：工具（论点 2）**：S0 对 S1（必要）；S1 对最终目录（不充分）；检测差距与组件替换（差在哪里）。
6. **结果二：知识与自动检验（论点 3）**：S2c、S3 对 S1；checker 挡住的错误；知识对 checker 的消融；差距弥合；checker 的使用与处置；规则来源案例与其他案例分开报告。
7. **结果三：到不了的部分（论点 4）**：速度模型、定标、尾波漏检；工具约定本身是误差来源；专家阶梯与干预编码；可信目录判定。
8. **讨论**：哪些目录维度、在什么情形下可以交给 Agent；哪些仍需要人或参考目录；局限（单一模型、运行数少、规则来自同一批案例）。

## 7. 正式运行前需要定下的事项

已定：正式比较用完整流程（含前端拾取、关联、模板匹配），后端版本只用于迭代和归因。

待定：

1. 是否运行 S2（只有知识、没有 checker）。知识中的小批量协议和方案决定都依赖 checker，单独拆开不自然。
2. 重复次数、第二个模型、保留案例是否纳入本轮。
3. 主要度量用"不通过的可信标准数"、"差距弥合率"，还是两者并列。
4. 水平偏移和深度偏差的固定 1 km 门槛，是否按最终目录自身离绝对定位参考的偏差放宽。

定下后冻结评分器、checker、知识、工具、提示词和 Agent 配置的提交号，再开始正式运行；运行后发现的问题只作附加分析。
