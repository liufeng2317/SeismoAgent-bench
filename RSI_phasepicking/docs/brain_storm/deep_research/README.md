# Deep research 汇总（2026-11-13）

对 [research_directions.md](../research_directions.md) 中 16 个方向的调研结果。每个方向一份报告，结构相同：要回答的问题、结论摘要、详细发现、对本项目的影响、未解决与待核、参考文献（每条标注 [已读原文] / [只读摘要] / [未打开原文]）。

**怎样读这些报告：**

- 调研由 8 个 agent 并行完成。共享的网页检索额度（200 次）在后期用完，部分条目只依据检索摘要或已知网址，报告中已逐条标注。
- 标为“推断”的数字是 agent 自己的计算（多为正态近似、假设方差），不是文献数值。
- 01、02、03 三份报告含**我们自己做的数据分析或模拟**，脚本在 [scripts/](scripts/)：
  - `scripts/01_02_analyst_picks/`：SCEDC/NCEDC 拾取的人工/自动比例抽样、CI 与 NC 两个台网分析员拾取的对比（36 个事件、374 对）。
  - `scripts/03_residual_detectability/`：留一台站残差能否检出单个拾取误差的蒙特卡洛模拟。
- [reference/](reference/) 放用户自己读过的原文。

## 1. 各方向一句话结论

| # | 方向 | 一句话结论 |
|---|---|---|
| [01](01_analyst_picks_scsn_ncsn.md) | SCSN/NCSN 分析员拾取 | 设计稿的日期都对，但“分析员计时无法区分”过时了：QuakeML 每个拾取有 `evaluationMode`；SCSN 终审事件中人工 P 拾取的比例从 2012 年的 99% 降到 2024 年的 45% |
| [02](02_pick_label_noise.md) | 拾取的标签噪声 | 两个台网分析员对清晰 P 的差异中位数 0.01 s、对缓起 P 和 S 约 0.05 s（90% 分位 0.30 s）；半合成（叠加真实噪声）不是新做法 |
| [03](03_residuals_as_pick_feedback.md) | 残差能发现多大的拾取误差 | 一维模型下残差主要是模型误差；单事件留一残差只能抓 ≥0.3–1 s 的粗差；系统偏差完全看不见。物理反馈教不了精细计时 |
| [04](04_where_dl_pickers_fail.md) | 拾取器在哪里失效 | 同距离范围跨区域只轻度退化；失效最明显的是火山长周期事件、海底台、区域/远震震相；意大利 52 万条拾取的对比中深度学习拾取总体优于人工 |
| [05](05_japan_data_and_pickers.md) | 日本数据和本地拾取器 | “PhaseNet 在日本失效”只在海底台、JMA 台站和 S 波上成立；日本训练的权重已进 SeisBench；JMA 有到时标签但没有极性，且禁止再分发 |
| [06](06_polarity_and_s_picking.md) | 极性和 S 波拾取 | 极性模型与分析员 95–99% 一致，已到标签噪声上限；P 到时误差比分类器更影响极性；极性基线用 Ross 2018 CNN，日本用 RPNet |
| [07](07_location_reference_catalogs.md) | 定位参考目录 | 没有一个目录是绝对位置真值；目录间差 0.25–0.47 km，深度基准不统一；Liu 2020 和 Atterholt 2025 本身来自深度学习拾取，评估对应基线时是循环的 |
| [08](08_vlm_reading_time_series_plots.md) | VLM 读时间序列图 | VLM 能找区间、读不准单点；要 0.02 s 精度需约 1 s 的放大窗或数值精修；尚无 VLM 在天然地震上拾取的已发表研究 |
| [09](09_fixed_workflow_vs_autonomous_agent.md) | 固定流程与自主 agent | 极简控制循环 + 强模型 + 好工具胜过复杂编排；建议“固定外壳 + 受限内层 agent + 按不确定度分级”，并加固定流程对照组 |
| [10](10_self_evolving_skills_memory.md) | 自我演化的技能和记忆 | agent 自评教训不可靠（与实测效果秩相关 0.21）；推荐三层记忆：流程 + ACE 式规则 + 带测试的代码技能 |
| [11](11_self_improvement_instability.md) | 自我改进的不稳定性 | 打乱事件顺序后记忆方法平均低于无记忆 4.5 分；最有效的缓解是“多个候选 + 保留空记忆 + 在新事件上选” |
| [12](12_learning_from_noisy_feedback.md) | 带噪反馈下的学习 | 自奖励会退化到平凡解；“预测留出台站”仍可刷；难刷的反馈要拿预测和 agent 改不了的波形证据比 |
| [13](13_learning_curve_statistics.md) | 学习曲线统计 | 统计单位是学习流（种子 × 顺序）；每组 3 条流只能检出约 7 个百分点的差异；拾取要按事件整群 |

## 2. 对设计的主要影响

### 2.1 先要定的事

| 问题 | 调研给出的依据 | 建议 |
|---|---|---|
| 用哪个模型看图 | GLM-5.3 只支持文本 [14]；前沿闭源模型在图表基准上已不可区分 [08] | 先用一个闭源模型打通，同时做 Qwen3.8-27B 的“只测看图”对比；若沿用上游运行框架并用 GLM 系列，要换 GLM-5.3-Flash |
| 编排方式 | 简单流程常以更低成本追平复杂 agent [09] | 固定外壳 + 受限内层 agent；对照组加“同模型同工具的固定流程”和“不用 LLM 的残差重拾” |
| 物理反馈（H3）的范围 | 残差只能抓粗差，系统偏差不可见 [03]；自奖励会退化 [12] | H3 限定为粗差：认错震相、错波列、漏拾 S、误拾；精细计时只用标签或半合成数据评价 |
| 日本 baseline 的定位 | 陆上 Hi-net 上 PhaseNet 还可以 [04][05] | 改为海底台、低频地震、火山和能登 2024 早期密集序列；对照组必须含 `jma`/`jma_wc`/`phasenet_sn` |

### 2.2 标签和真值

- 只用 `evaluationMode=manual` 的拾取当标签 [01]。
- 避开 SCSN 用 PhaseNet 做后处理的日期：2023-11 起的 M<3 事件，以及几个 hypoPN 测试日期 [01]。
- 按层设定标签噪声底线，而不是用 Ross 2018 的 0.023 s [02]：

| 拾取类型 | 分析员间差异（中位数 / 90% 分位） |
|---|---|
| 清晰 P | 0.01 s / 0.04 s |
| 缓起 P | 0.05 s / 0.30 s |
| S | 0.05 s / 0.30 s |

- 机构之间有系统偏差，比如原始 PhaseNet 比 JMA 和意大利的人工拾取都偏晚。所以比较前要先估计并扣除常数偏差，否则“更准”可能只是“更像这家机构” [04]。
- 定位主指标：相对于“同一定位器、同一速度模型、分析员拾取”的定位位移。外部目录只作合理性检查，比较前先统一深度基准 [07]。

### 2.3 实验规模与门控

- 每组至少 6 条学习流（3 种顺序 × 2 个种子）；要说“物理反馈与标签反馈相当”，需要做等效性检验，每组约 16–17 条流 [11][13]。
- 设计稿的门控太严：80 个门控事件上同时要求四项指标非劣，一个真正无害的更新只有约 10% 的概率全部通过；门控预算也低估了 3–8 倍 [11][13]。
- 改为：保留多个候选记忆，加上空记忆，在新事件上选择（RBC 的做法）[10][11]。
- 安慰剂反馈和等算力的 best-of-N 对照必须做，而且要按 token 数和调用数对齐 [12]。
- 试点中按拾取算的 p 值要改为按事件整群重算 [13]。
