# LLM 地震分析员 Agent

## 1. 定位与新颖性

### 1.1 最接近的已有工作

| 工作 | 内容 | 与我们的区别 |
|---|---|---|
| **FA-Agent**（Li & Yuan, arXiv 2611.06555, 2026-11，投稿 *Geophysics*） | GPT-6 多模态 agent 目视拾取勘探地震初至波：先扫描道集，再放大问题区，保留、修正或删除初始拾取；配有技能库和专家复核案例库 | 处理的是勘探数据，不是天然地震；没有 S 波、极性和定位；反馈来自专家人工；**没有度量学习曲线**，也没有和深度学习基线对比 |
| **TRACE**（arXiv 2603.21152，我们自己的工作） | 多 agent 调度深度学习拾取器、关联和 HypoDD，构建 Ridgecrest 目录 | TRACE 是**调度工具**；本工作中 agent **自己就是分析员**，在单道波形层面工作，并且会学习 |
| SeisMoLLM（GRL 2026）、MULTISEISMO（arXiv 2605.26320） | 用 LLM 骨干直接处理波形，或构建多模态指令数据集 | 不是 agent，不看图；MULTISEISMO 报告通用多模态模型处理地震时间序列效果差，这正好支持"需要工具和绘图"的设计 |
| SCSN 业务化 ML（Tepp et al. 2025, *Sci. Rep.*；Zhou et al. SCEC 2026） | PhaseNet + GaMMA 进入后处理，四种拾取器共识编目，分析员仍在环中 | **目前没有 LLM 或 agent 参与台网事件复核**，这是我们的切入点 |
| Münchmeyer et al. 2022 *JGR* | 深度学习拾取器的基准评测：大残差主要来自低信噪比和缓起震相 | 用来说明"缓起震相难"是已知问题 |
| On the Fragility of Self-Improving Agents（arXiv 2608.18066） | 自我改进 agent 方差大、受任务顺序影响 | 解释试点中学习不单调的现象 |

Advikar 的 workshop 版本仍然没有找到。可能的投稿去向是 NeurIPS 2026 TTCL workshop（关注测试时持续学习的 agent）。**需要直接问本人或老师。**

### 1.2 主张的强弱分级

| 主张 | 状态 | 写法 |
|---|---|---|
| 多模态 agent 端到端完成天然地震分析员工作（拾取、极性、定位、残差驱动重拾） | **新** | 主卖点 |
| 只用物理残差反馈、不更新权重的跨事件学习 | **新**（H3） | 主卖点 |
| 有对照、有统计检验的学习曲线（含安慰剂记忆） | **新** | 主卖点 |
| 缓起震相上精度约 2 倍 | 有潜力，但**受标签噪声影响** | 必须用半合成数据证实 |
| 极性约 95% | **持平** | 只说"可比"，并通过下游震源机制质量体现价值 |
| 看图拾取 + 技能记忆 | FA-Agent 已提出（但用于勘探数据） | 引用并说明区别 |

**摘要定位句（草稿）**：深度学习拾取器已在台网承担大部分预处理，但最终的拾取、极性和定位仍依赖人工分析员。现有 LLM 系统要么调度这些拾取器，要么用于勘探道集。本文展示，具备视觉能力的 LLM agent 可以端到端完成天然地震的分析员工作，并通过基于物理残差、自带证据的 playbook 在事件之间持续改进，无需重新训练。

## 2. 研究问题与假设（修订）

| 假设 | 内容 | 主要证据来源 |
|---|---|---|
| **H1** | 在缓起、低信噪比震相上，agent 的拾取**精度**显著优于深度学习拾取器；在清晰震相上与之持平 | **半合成数据**（主）+ 按分析员起始标记 i/e 分层（辅） |
| **H2** | 在门控更新协议下，自写记忆带来**可重复、近似单调**的提升，且显著优于安慰剂记忆和等算力对照 | 多种子、多顺序的学习曲线 |
| **H3** | **只用物理反馈**（无人工标签）也能获得与标签反馈相当的学习收益 | 标签组 vs 物理组 vs 安慰剂组 |
| **H4** | 分级处理可在成本大幅降低的同时保持质量，能扩展到整个序列（约 6,700 个事件） | 成本–性能帕累托曲线 |

## 3. 数据与真值设计（v2 核心改动）

### 3.1 SCSN 参考拾取的实际情况

- **2013-04 起**：后处理改为以自动拾取为主，只有最近的 5–10 个台站精确计时，约 100 km 以外的拾取大多被丢弃。
- **2015-01 起**：所有事件都经过复核，但很多只是目视检查；完整人工分析只针对 M≥2.5、RMS≥0.4 或深度/震级异常的事件。**目录没有字段区分哪些是人工计时。**
- **2023-11 起**：M<3 事件的后处理改用 PhaseNet 代替 STA/LTA，分析员从 PhaseNet 的结果开始复核，造成**参考拾取偏向 PhaseNet**。
- **2019 Ridgecrest 复核进度**：07-04 和 07-05 为 100%，07-06 为 97%，07-07 为 23%，07-08 至 07-10 约 10–12%。ComCat 把所有事件都标为 "reviewed"，这个标记无法区分人工计时。
- **相位文件格式**（`s3://scedc-pds/event_phases/YYYY/YYYY_DOY/<evid>.phase`，STP 格式）：
  - 极性：c. / d. / ..
  - 起始类型：i（清晰）/ e（缓起）
  - 质量：1.0 / 0.8 / 0.5，大概对应 Hypoinverse 权重 0 / 1 / 2 **[待核 STP 手册第 34 页]**
- **参考拾取很稀疏**：M7.1 主震只有 95 个拾取（P 79 个、S 16 个）。

### 3.2 数据集划分

| 数据集 | 时段与区域 | 用途 | 说明 |
|---|---|---|---|
| **练习池（Practice）** | 2020-01 至 2023-10，Ridgecrest/Coso 区域，已终审 | 学习流（标签反馈或物理反馈） | 晚于 2015 年政策，早于 PhaseNet 进入后处理；与测试集在时间上分开 |
| **门控集（Gate）** | 同一练习时段中单独抽取 80 个事件（按震级、震中距、信噪比分层） | 判断是否接受记忆更新 | 每接受 10 次更新，轮换其中一半，防止对门控集过拟合 |
| **主测试集 T1** | **2019-07-04 至 07-06**，Ridgecrest，约 6,700 个事件 | H1–H4 主结果；从中分层抽 400 个事件做多组对比，全量只跑最佳 agent 组和各基线 | 复核完成度 ≥97%，没有 PhaseNet 偏向；**需要防止模型记住这次地震**（见 3.4） |
| **辅助测试集 T2** | 2026-07 之后，SCEDC + NCEDC，M≥2.5，约 100–150 个事件 | 晚于模型训练截止，没有记忆污染 | 参考拾取可能偏向 PhaseNet，需在文中说明；**H1 和 H2 结论须在 T1 和 T2 上方向一致** |
| **半合成集 T3** | 从 T1 和练习池中选高信噪比、起始类型为 i、质量 1.0 的拾取 | **精度的主证据** | 叠加同一台站同一通道的事件前真实噪声，信噪比从 −5 到 20 dB 扫描。没找到用真实噪声做这类基准的已发表工作 **[待核]**，可能是新做法 |

### 3.3 分层与标签噪声底线
- 所有指标都按以下维度分层：M≥2.5 / M<2.5；起始类型 i / e；质量 1.0 / 0.8 / 0.5；震中距（是否属于最近的 5–10 个台站）。
- **标签噪声底线**：Ross 2018 的 CNN 与分析员 P 拾取相差 σ=0.023 s；分析员之间约 0.1–0.2 s **[待核：Zeiler & Velasco 2009，Freedman 1966]**。
  - 低于这个底线的差异，只能写成"与分析员更一致"，**不能写成"更准确"**；
  - "更准确"只能由 T3 半合成数据支撑。

### 3.4 防记忆污染（T1 用的是 2019 年数据）
1. 窗口时间整体平移，隐藏绝对日期；
2. 台站名称匿名化，坐标做刚体平移或旋转，在宿主机上定位后再变换回来；
3. 对照检查：比较匿名化与否时 agent 的表现。若匿名化后明显变差，说明存在记忆污染。

### 3.5 定位参考
- 绝对位置：Hauksson–Yang–Shearer（HYS）重定位目录与 ComCat。
- 经验"真值带"：用多个高精度目录之间的离散程度作参考，包括 Ross 2019 QTM（约 100 m 水平、350 m 垂直，相对精度；M7.1 深度约束差）、Shelly 2020、Lin 2020（相对误差 8 m / 16 m）、Atterholt 2025。
- 注意：这些目录给的是**相对精度**，不代表绝对位置准确。

## 4. 实验组设计

### 4.1 基线（不用 LLM）

| 组 | 内容 |
|---|---|
| B1 / B2 / B3 | PhaseNet / EQTransformer / GPD，均用 SeisBench 的 `scedc` 权重，关联统一用 PyOcto（1D 模型） |
| B4 | **PhaseNO**（多台站模型，从 Zenodo 获取权重，用 NCEDC 数据训练） |
| B5 | **PhaseNet + AIC 精修**，与 agent 用同一个 AIC 函数 |
| B6 | **STA/LTA + AIC 精修** |
| B7 | 极性模型：Ross 2018 CNN、DiTingMotion（可通过 SeisPolarity 封装调用 **[待核质量]**） |
| B8 | 分析员拾取直接定位，作为定位上限 |

定位器：Hypoinverse + Hadley–Kanamori 模型（Vp/Vs=1.73）为对照；VELEST（以 Hadley–Kanamori 为初值，输出台站校正）为增加组，只在记录良好的子集上运行。

### 4.2 Agent 组

| 组 | 记忆 | 回答的问题 |
|---|---|---|
| A0 | 空记忆 | 零样本能力 |
| A-expert | 专家手写的固定 playbook | 自学记忆是否优于人工经验 |
| A-expert+L | 专家 playbook + 学习 | 两者能否叠加 |
| **A-label** | 用标签反馈学到的记忆 | 复现试点的设置 |
| **A-physics** | 用物理反馈学到的记忆（不看任何分析员拾取） | **H3** |
| **A-placebo** | 反馈来自另一个事件（错配），token 数和调用次数相同 | 排除"反思过程本身就有用" |
| A-generic | 长度相同的通用地震学说明 | 排除"上下文更长就有用" |
| A-bestofN | 无记忆，用同等算力做 best-of-N 或自洽投票 | 排除"多花算力就有用" |

消融（视预算而定）：不做内循环；不看图只用数值；加上数值片段的混合输入；逐事件反思 vs 批量反思；整体重写 vs 增量编辑；有门控 vs 无门控。

## 5. 记忆更新协议（解决学习不单调）

1. **数据划分先冻结**：练习流、门控集、测试集在实验开始前固定。
2. **批量反思**：每 B=20–25 个练习事件反思一次。反思时看的是**汇总误差表**（按震相、震中距区间、台站类型分组），而不是单个事件。一条新规则至少需要本批次中 3 个事件支持。
3. **只做增量编辑**：对单条规则做增加、修改、删除、合并四种操作。每条规则写明适用条件、动作、预期影响的指标和证据。**不允许整体重写 README**，以避免记忆被压缩到失真。
4. **技能函数**：每个新增或修改的函数都要通过单元测试，并在 10 个事件的回归子集上**所有指标不退步**。
5. **门控（每个指标都要非劣效）**：
   - 在门控集上，用固定温度、2 个随机种子运行"候选记忆"和"当前记忆"；
   - 主指标：P、S 拾取 F1（容差 0.1–0.2 s）与定位误差的综合；
   - 接受条件：主指标差值的配对 bootstrap 90% 置信区间下界大于 0；
   - **同时每个次要指标的退步都不能超过阈值**：P 或 S recall 不降超过 2 个百分点，极性不降超过 2 个百分点，定位中位误差不增超过 10%；
   - 试点中 after_9 加入的那条严格 S 规则，会因 S recall 下降而被这个门控拒绝。
6. **定期整合（每 5 个批次一次，参照随机分组消融方法）**：
   - 把规则聚成约 8 组；
   - 在约 150 个练习事件上，每组规则以 50% 概率随机开启；
   - 用带事件固定效应的岭回归估计每组的贡献，删除贡献 ≤0 的组；
   - 上限约 40 条规则或 3k token；
   - 最后在门控集上从"整合版 / 完整版 / 上一版 / 空记忆"中选最优。
7. **版本管理**：每个被接受的版本都打 git tag；实际使用的始终是门控中得分最高的版本，相当于自带回滚。

## 6. 物理反馈设计（H3）

- **反馈内容**：
  - VELEST 联合反演后的残差和台站校正；
  - 留一台站残差；
  - Wadati 图（预期斜率约 0.73，对应 Vp/Vs=1.73）的离群点；
  - S−P 时间与震中距的一致性；
  - SKHASH 震源机制的极性拟合误差。
- **完全不包含分析员拾取。**
- **防刷分约束**：以上物理分数都可以靠"少拾取、丢难拾取"变好，所以必须同时约束拾取数量、方位角空隙和 S 拾取数量，任何一项低于基线就判为不合格。论文中要报告这些覆盖度指标随学习的变化。
- 物理组的门控指标换成"物理分数 + 覆盖度约束"，但最终评估仍在有标签的测试集上进行。

| 工具 | 用途 | 依据 |

## 8. 扩规模方案

### 8.1 开源模型能否替代 GPT-6.1：两步测试
1. **只测看图能力（便宜，先做）**：
   - 从 300 个分层事件中取 GPT 已生成的约 1,500 张图，按基线不确定度分为易、中、难三档；
   - 让 Qwen3.8-27B、Gemma 4 31B 和 GPT-6.1 各自单轮读出起始时刻和极性；
   - 目的：区分模型是"看不准"还是"不会用工具"。
2. **完整 agent 运行**：同样 300 个事件，每个模型重复 3 次，工具和提示词完全相同。
3. **判定标准**（事件层面配对 bootstrap，阈值事先确定）：
   - **全面替代**：极性不差超过 2 个百分点，0.1 s 内命中率不差超过 3 个百分点，任务完成率 ≥95%；
   - **部分替代**：只在易、中两档满足上述条件，则用于分级处理的第一层。

### 8.2 分级处理架构

| 层级 | 运行位置 | 内容 |
|---|---|---|
| T0 | CPU，确定性计算 | 从 S3 预先下载波形；SeisBench 多模型集成 + 时间平移增强；极性 CNN；预先渲染标准长条图；计算每个拾取的难度分数（峰值概率、模型间离散度、极性置信度、信噪比、震中距） |
| T1 | 集群开源模型 | Qwen3.8-27B（FP8，用 vLLM 在 Apptainer 中运行，单卡，32–64 个并发 agent，开启前缀缓存）；处理所有事件，agent 与集成模型一致的拾取直接接受 |
| T2 | GPT-6.1-sol（Flex 档 + 缓存） | 只处理 T0 判为困难或 T1 不一致、低置信的拾取，预计占 15–30%；另外**随机抽 5% 的"简单"事件做审计**，估计分级处理漏掉了多少问题 |

- **集群部署**：可参考 Kempner Institute 在 FASRC 上测试过的 vLLM Slurm 配置；可用分区包括 `gpu_h200` 和 `gpu_requeue`。
- **数据获取**：`s3://scedc-pds` 公开且不需请求方付费；按"事件日 × 台站"一次性下载到 scratch，不要在每次 agent 调用时现取。

### 8.3 预算估算

价格依据 OpenAI 官网：gpt-6.1-sol 输入 $2、输出 $10（每百万 token），缓存命中输入 $0.10；Flex 和 Batch 档半价。

| 实验 | 运行次数 | GPT 标准价 | Flex + 裁图 |
|---|---|---|---|
| T1 分层 400 个事件 × 8 个 agent 组 × 3 个种子 | 9.6k | 约 $5.8k | 约 $2.4k |
| 学习流：3 种反馈 × 3 个种子（每个种子对应不同顺序）× 每流约 600 次（200 练习 + 门控） | 5.4k | 约 $3.2k | 约 $1.4k |
| T1 全量约 6,700 个事件，只跑最佳组 | 6.7k | 约 $4k | 约 $1.7k |
| **合计** | — | 约 $13k | **约 $5.5k** |

- 如果开源模型通过测试，学习流可以扩展到调研建议的规模（≥5 个种子 × 3 种顺序、每流 600–1,500 个练习事件），只消耗 GPU 时间。粗估约 0.5–1 GPU 分钟/事件 **[待在试点中实测]**。
- 老师表示必要时可花几千美元买额度，Flex + 裁图方案在这个范围内。

## 9. 评估与统计

- **拾取指标**：precision、recall、F1、MAE、0.05 s 和 0.1 s 内命中率，按 §3.3 的维度分层；P 和 S 分开统计。
- **精度**：在 T3 半合成数据上，画误差随信噪比变化的曲线（主证据）。
- **极性**：与分析员的一致率（分 i/e 起始类型）；用 SKHASH 计算震源机制，与 Cheng 2023 / Yang–Hauksson–Shearer 目录中 A–B 级机制的差异。
- **定位**：与 HYS/ComCat 的偏差，以及是否落在多目录"真值带"内。
- **学习**：在 0、25、50、100、200 个练习事件处取快照画学习曲线；计算曲线下面积和斜率检验；用以事件和种子为随机效应的混合效应模型；四分位均值（IQM）+ 分层 bootstrap 置信区间。
- **归因**：对最终 playbook 做逐组剔除的消融；检查记忆能否迁移到另一个模型或另一个地区（NCEDC）。
- **成本**：每事件的 token 数、图片数、工具调用数、美元或 GPU 时间、耗时。

## 12. 风险与备选

| 风险 | 备选 |
|---|---|
| 半合成数据中 agent 的优势消失 | 重点改为"端到端 + 可解释的决策记录 + 学习能力"，精度只写持平 |
| 门控后学习收益很小 | 如实报告"未经门控的学习不可靠，门控后收益有限"，这本身也是有价值的方法学结论 |
| 物理反馈组无效 | 报告与标签反馈的差距，讨论无标签场景（没有分析员的台网）的适用性 |
| 开源模型不通过测试 | 用 GPT Flex + 分级处理，把 T1 全量运行范围缩小到 07-04 至 05 |
| T1 存在记忆污染 | 以匿名化后的结果和 T2 为准 |
| 记忆仓库中泄漏事件信息 | 保留泄漏检查；记忆中不得出现事件 ID、坐标或台站特定答案 |
