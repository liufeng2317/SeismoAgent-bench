# KERANEN2013_G34045

Keranen, K. M., Savage, H. M., Abers, G. A., & Cochran, E. S. (2013).
Potentially induced earthquakes in Oklahoma, USA: Links between wastewater
injection and the 2011 Mw 5.7 earthquake sequence. Geology 41(6), 699–702.
DOI https://doi.org/10.1130/G34045.1.

- Supplement: GSA Data Repository item 2013191 (DOI 10.1130/2013191,
  figshare article 12529799, file 23295632, md5
  4b5c114c756c83c4c65f4b34f12e1d45), downloaded 2026-10-23 to
  `supplement/KERANEN2013_G34045__supplement_2013191.pdf`.
- Role in this case: source of the local 1-D velocity model used by
  Cochran et al. (2020) for the primary reference catalog. The model is
  published only as Figure DR1 (vector graphics, page 4); its best-fitting
  (dashed) Vp/Vs curves are extracted exactly by
  `scripts/models/digitize_keranen2013_dr1.py` into
  `data/models/velocity_models.json` (`keranen2013_prague_1d`).
