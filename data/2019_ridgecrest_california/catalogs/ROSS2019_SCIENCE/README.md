# Ross et al. (2019) Ridgecrest QTM catalog

- `source_ref`: `ROSS2019_SCIENCE`
- Article: Ross et al. (2019), *Hierarchical interlocked orthogonal faulting in the 2019 Ridgecrest earthquake sequence*, DOI [10.1126/science.aaz0109](https://doi.org/10.1126/science.aaz0109).
- Official data page: [SCEDC QTM Ridgecrest catalog](https://scedc.caltech.edu/data/qtm-ridgecrest.html).
- Raw archive: `raw/ROSS2019_SCIENCE__catalog_qtm.tar.gz`.

The SCEDC release is the article-associated QTM/GrowClust-format catalog. It contains relocated origin parameters, event and cluster IDs, differential-pair counts, residuals, location errors, and initial catalog locations. The SCEDC page warns that the Mw 7.1 mainshock depth is poorly constrained; use the SCSN hypocenter for that event.
