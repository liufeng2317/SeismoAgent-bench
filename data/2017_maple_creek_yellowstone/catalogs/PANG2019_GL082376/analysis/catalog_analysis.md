# PANG2019_GL082376 catalog analysis

This reference cannot be statistically or visually processed yet because the local machine-readable Pang event table is not present. The article reports a 3,345-event absolute catalog and 3,257 GrowClust relocations, but those values are article-level claims, not a local-file audit.

The similarly named Shelly phase-arrival files are not substituted: they contain phase arrivals and do not provide the Pang event coordinates. Once the author/publisher event table is acquired, this directory should receive a native-format parser, benchmark statistics, and the standard spatial/time/magnitude figures.
