All figures have PNG and PDF versions. Record-section processing, coverage and distance tables: [Mw 6.4](mw6_4_record_section.md) and [Mw 7.1](mw7_1_record_section.md). Distances and station order are calculated separately for each earthquake. Every trace is independently normalized; heights must not be compared as physical amplitudes between stations or earthquakes. Mw 7.1 suspected-saturation flags are event-specific.

`waveform_audit.json` belongs to the historical archive comparison and short three-station examples. It is not the current external waveform inventory. Raw waveform data remain unchanged.
