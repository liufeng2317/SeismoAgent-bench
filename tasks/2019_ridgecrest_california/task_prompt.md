# Ridgecrest earthquake catalog construction

Construct a reproducible earthquake-catalog candidate from the waveform and
StationXML files listed in the input manifest. Inspect the available traces,
identify candidate seismic events, and record event times, locations or
location status, and provenance for the observations used. Do not modify the
declared inputs or claim scientific completeness beyond the available data.
Write the catalog artifact to the declared output path and preserve uncertainty
or unresolved fields explicitly.
