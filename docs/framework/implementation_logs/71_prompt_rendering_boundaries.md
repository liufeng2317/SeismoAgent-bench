# Prompt rendering boundaries

## Implemented

- Kept task-specific instructions in `task_prompt.md` and removed concrete
  input paths, dates and artifact filenames that are already supplied by the
  manifest or output contract.
- Added a dedicated `### Task instructions` section in the rendered prompt.
- Standardized the task prompt headings below that section so the generated
  Markdown has a predictable hierarchy.
- Kept input tables, output tables and runtime paths generated by the renderer
  as the structured source of truth.

## Validation

The rendered Ridgecrest prompt was inspected for duplicate sections and the
task, artifact and workflow tests passed.
