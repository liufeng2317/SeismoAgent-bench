# 研究计划 A：Agent 构建地震目录的基准（SeismoAgentBench）

**定位：** 备选工作。主线是 [研究计划 B：checker](./01_Research_Plan_Checker.md)；两条线共用案例、评分和运行。如果 checker 的效果不足以单独成文，本计划可独立成文：只回答"Agent 现在能做到什么程度"，不依赖 checker 是否有效。

**名称：** SeismoAgentBench（Agentic Seismic Catalog Benchmark），仓库和命令行用 `seismoagent-bench`。

## 1. 问题

> **通用 Agent 能在多大程度上独立地从连续波形构建地震目录，质量能达到什么水平，哪些地方仍离不开专家？**

评估的是完整工作流（拾取 → 关联 → 绝对定位 → 相对定位 → 震级 → 目录），不是单个算法。结果与 human-in-loop 最终目录比较；参考目录对 Agent 扣留。

## 2. 案例

六个持续 3–8 天的序列，覆盖不同的地震情形和台网条件，按运行之前已知的特征分为三级（台站数、窗口、事件率；每天事件数取自 human-in-loop 最终目录）。

| 分级 | 案例 | 情形 | 台站 | 窗口 | 事件/天 | 主要难点 |
|---|---|---|---:|---|---:|---|
| 基础 | Prague 2011 | 诱发地震的余震 | 23 | 8 d | ~850 | 紧凑台网，布设变化 |
| 基础 | Magna 2020 | Mw 5.7 主震–余震 | 47 | 8 d | ~680 | 盆地速度结构，深度控制 |
| 中等 | Maple Creek 2017 | 黄石震群 | 27 | 8 d | ~1,550 | 只有垂直分量的台站，小事件多 |
| 中等 | Kīlauea 2018 | 火山山顶塌陷，Mw 6.9 | 25 | 8 d | ~650 | 三维结构，大震尾波 |
| 困难 | Ridgecrest 2019 | M6.4、M7.1 序列 | 42 | 3 d | ~6,000 | 尾波、极高事件密度 |
| 困难 | Kaikōura 2016 | Mw 7.8 多断层余震 | 53 | 8 d | ~1,600 | 260 km 台网，一维与三维框架差 |

候选池和案例登记见 [`docs/data/`](../data/)。

## 3. Agent 阶段

Agent、harness、模型和输出约定不变，每一阶段只多一个因素（只往 Agent 的环境里加文件）。

| 阶段 | 变体 | Agent 额外得到 | 回答的问题 |
|---|---|---|---|
| S0 | `min` | 任务、数据、输出约定 | 通用 Agent 能否独立完成？ |
| S1 | `tools` | 验证过的工具库 `seismotools/` 及其文档 | 工具带来什么？ |
| S3 | `knowledge` | + checker（`seismo_checker/`）、checker skill、知识 skill | 经验带来什么？（见计划 B） |
| — | human-in-loop 最终目录 | — | 上限和标尺 |

`checker` 变体（S2c，只有 checker、没有知识）只在需要消融时运行。正式比较用完整流程（2026-11-05 决定），后端版本（拾取和关联固定）只用于迭代和归因。其他输入条件（给常规目录、给拾取）和指导设置（开放文献、专家指导）留作以后的任务。

## 4. 评分

- **标尺：** human-in-loop 最终目录。它在迭代中看过参考目录，所以是上限，不是盲结果；差距用专家阶梯归因。
- **可信目录标准：** 先判事件是否真实，再判时间、空间、强度（震级）的准确性和稳定性。完整性单独报告，不参与判定。门槛对所有阶段相同。不给综合分数，也不排行。
- **参考目录：** 每个目录只承担它能支撑的角色（检测、绝对定位、相对结构、震级、拾取），不当作全维度的真值。
- 定义见 [`03_Scoring_Method.md`](./03_Scoring_Method.md) 和 [`02_Catalog_Metrics.md`](../framework/02_Catalog_Metrics.md)。

## 5. 有效性

- **泄漏：** 参考目录和目标论文对 Agent 扣留；运行记录 Agent 访问过的网址和路径，命中扣留产品的运行排除。
- **运行环境：** 共享环境写保护，Agent 只能在自己的运行目录里装包；每次运行记录工具库和 checker 的版本。
- **重复与泛化：** 先在 S1、S3 上重复；第二个模型在每个分级各取一个案例；可选一个不参与规则总结的保留案例。

## 6. 产出

一张能力图谱，而不是一个分数：任务是否完成、各维度离专家多远、瓶颈在哪个阶段、失败的方式、计算成本，以及这些如何随案例变化。

## 7. 现状（2026-11-05）

- S0、S1 在六个案例上已运行和评分。工具让所有案例都能完成，不通过的判据大幅减少；但没有一个运行达到可信标准，S1 只找回最终目录 22–51 % 的事件（[大纲 §4.1](./02_Paper_Outline.md)）。
- 主要差距：检测上，五个 tools 运行没有把模板匹配的检测加进目录；定位上，时间和深度偏差来自近地表速度和基准面（[检验记录 09、10](./progress/checker_validation/README.md)）。
- 待定：重复次数、第二个模型、保留案例、主指标、偏移门槛（[大纲 §6.5](./02_Paper_Outline.md)）。
