# 从数据建速度模型：最小一维模型加台站校正（2026-11-03 至 11-04）

不向 Agent 提供具体速度模型（2026-11-03 决定）之后，地震学家的标准做法是从数据自己建模型：在一维模型和台站校正之间联合搜索，按走时残差选（VELEST 的最小一维模型）。[05_near_surface_magnitude_matching.md](05_near_surface_magnitude_matching.md) 检验了按地质加低速表层；这里检验另一条路：只缩放整列速度，加台站校正，按残差选。

## 方法

脚本 `workflows/development/replay/velocity_from_data.py`，汇总 `velocity_from_data_summary.py`，输出 `outputs/velocity_from_data/`（不纳入版本库；NonLinLoc 走时网格已于 2026-11-04 删除，每一步的目录和 JSON 保留）。

- **数据：** 与 05 相同，每个案例正式 tools 运行的代表性小批量，300 个事件、它们的拾取，起点是 05 的通用 CRUST1.0 柱（Vs 用数据的 Wadati Vp/Vs，顶面在台站平均高程）。
- **模型：** 整列速度乘以同一个系数：0.88、0.94、1.00、1.06、1.12。Prague、Maple、Kīlauea、Magna 另加 0.76、0.82（`lowscale`），因为它们在 0.88 处残差仍在下降。
- **定位与台站校正：** 每个系数先用 NonLinLoc EDT_OT_WT 定位，再迭代 3 轮台站校正。每轮取每个台站每个震相（至少 10 个拾取）的残差中位数，减去同一震相的全台网中位数（不让校正吸收共同偏移），累加。
- **阻尼变体（`damped`）：** 每轮只加一半，累计不超过 ±0.3 s。
- **选择规则：** 在所有系数和迭代中取 RMS 中位数最小的一步（VELEST 的做法）。参考目录只用来给每一步打分（相对 human-in-loop 最终目录的时间偏差、深度偏差、水平偏移），不参与选择。通过 = |时间| ≤ 0.3 s、|深度| ≤ 1 km、水平偏移 ≤ 1 km（可信标准的门槛）。

**只加台站校正、不缩放（×1.00，3 轮）：**
- 变好：Maple 深度 −3.22 → −0.06 km；Ridgecrest 水平 1.06 → 0.79 km。
- 变差：Prague 深度 +0.69 → +1.88 km；Kaikōura 深度 −4.63 → −5.21 km；Magna 深度 +1.12 → +7.76 km（第 2 轮）。

**阻尼变体：**
- Magna 选中模型的深度偏差从 +6.62 降到 +3.72 km，仍然失败。
- Kaikōura 的最小残差移到 ×1.00，深度回到 −4.96 km。
- Prague 选中 ×0.94，深度 +1.06 km，不再通过。

阻尼不能防止失效，反而削弱了有效的情况。

## 结论

1. **按残差选"缩放加台站校正"在四个案例上有用，在一个案例上没变化，在一个案例上出错。**
   - 有用：Kīlauea 由不通过变为通过；Kaikōura 深度偏差从 −4.6 km 降到 −0.7 km，水平偏移从 1.66 km 降到 1.01 km；Maple 深度从 −3.2 km 降到 −0.1 km，水平从 2.2 km 降到 0.6 km，但时间仍偏晚 0.7 s；Prague 本来就通过，深度更准。
   - 没变化：Ridgecrest。
   - 出错：Magna 深度系统偏深 1.9–6.6 km，取决于搜索范围。

   比 05 中按单一测量量挑低速表层好，但不是可靠规则。
2. **台站校正会吸收结构误差，也会制造结构误差。** 在 Magna，校正与深度一起漂移：只加校正，深度偏差就从 +1.1 km 变成 +7.8 km。即使每轮都去掉全台网中位数，校正与深度、发震时刻之间的权衡仍然存在。阻尼只减慢漂移，不改变方向。
3. **唯一看到的无参考警示：残差最小值落在合理速度范围之外。** Magna 的 RMS 一直降到 ×0.76（比通用柱慢 24 %），搜索范围内没有内部极小。其余五个案例都在 ×0.82–1.00 内有内部极小。但内部极小不保证正确：Ridgecrest 的极小在 ×1.00，深度仍偏深 2.2 km。台站校正的平均大小（0.06–0.40 s）也不区分对错，Prague 选中模型的校正最大（0.40 s），结果却通过。
4. **残差附近的模型给出的深度差，应作为不确定度的下限报告。** RMS 在最小值 20 % 以内的模型之间，深度偏差相差：
   - Prague（×0.88–0.94）0.65 km；
   - Kīlauea（全部系数）0.7 km；
   - Kaikōura（×0.94–1.00）4.5 km；
   - Magna（×0.76–0.82）1.6 km；
   - Maple（×0.82–0.88）0.15 km；
   - Ridgecrest 只有 ×1.00 一个模型在范围内。

   只有 Maple 的范围包含正确深度（偏差 0），其余案例的正确深度都在范围之外，所以它只是不确定度的下限。这个离散在 Agent 不看参考时也能算出来。
