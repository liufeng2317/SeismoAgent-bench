# 水平偏移的来源：逐项替换（2026-11-05）

[05](05_near_surface_magnitude_matching.md) 的十个一维候选模型（通用柱和加低速表层）在 Kaikōura、Magna、Maple 上，相对 human-in-loop 最终目录的水平偏移都在 1.1–2.9 km，超过可信标准的 1 km 门槛。换一维模型消不掉这个偏移，那么它来自哪里？

## 方法

脚本 `workflows/development/replay/horizontal_shift.py`，输出 `outputs/horizontal_shift/`（不纳入版本库）。数据与 05、08 相同：每个案例正式 tools 运行的 300 个事件的代表性小批量。所有步骤都用 NonLinLoc EDT_OT_WT 定位，每一步只换一个成分。

| 步骤 | 拾取 | 速度模型和基准面 | 台站延迟 |
|---|---|---|---|
| 通用 | Agent | 通用 CRUST1.0 柱（05 的候选） | 无 |
| 专家模型 | Agent | 最终目录用的一维模型和基准面 | 无 |
| 专家延迟 | Agent | 同上 | 最终目录那一轮 NonLinLoc 的台站延迟（只有 Prague、Kaikōura、Maple 有） |
| 专家拾取 | 最终目录对同一批事件的拾取（按评分器配对） | 同上 | 同上 |
| 专家拾取，只用 Agent 的台站 | 同上，去掉 Agent 没有拾取的台站 | 同上 | 同上 |

- **偏移的定义：** 与评分器相同，即配对事件东西、南北偏差的中位数。每一步都同时对最终目录和各参考目录计算。
- **检验设置：** 如果设置正确，"专家拾取"应该复现最终目录。所以"专家延迟"与"专家拾取"之差是拾取造成的部分，"专家拾取"与"只用 Agent 的台站"之差是台站组合造成的部分。

## 结论

1. **拾取和台站组合几乎不贡献。** 换成专家的拾取，偏移最多变化 0.26 km；只保留 Agent 用过的台站，最多变化 0.04 km。前端不是水平偏移的来源。
2. **Kaikōura、Maple 的偏移来自台站延迟。**
   - 加上最终目录的台站延迟后，偏移从 1.55 km 降到 0.46 km（Kaikōura），从 2.96 km 降到 0.24 km（Maple）。
   - 只换模型不加延迟，偏移反而比通用柱更大，方向也变了。台站延迟与模型共同决定了绝对框架：模型越接近真实，延迟越小；但在横向不均匀的地方，没有延迟的一维模型会使整批震中平移。
   - 在 Maple，这个框架也更接近参考：相对 ComCat 从 3.76 km 降到 0.83 km。
   - 这与 [08](08_velocity_from_data.md) 一致：Agent 自己从数据算出的台站校正，也把 Maple 的偏移从 2.2 km 降到 0.6 km，Kaikōura 从 1.7 km 降到 1.0 km。
3. **Magna、Ridgecrest 的最终目录框架来自双差重定位，单靠绝对定位复现不了。** 用最终目录自己的拾取、模型和 NonLinLoc 定位，仍与最终目录差 2.29 km（Magna）和 0.85 km（Ridgecrest）。Ridgecrest 的这个差就是第 62、63 步记下的框架平移（hypoDD 用 Shelly 的分层模型、不考虑台站高程）。
   - Magna 用专家模型做绝对定位，离三个参考都更远（2.5–2.8 km），通用柱反而更近（0.8–1.1 km）。可能的原因是：专家模型带 2 km 的盆地充填层（盐湖谷），一维模型把它放到所有台站下面，包括山区台站，于是整批震中向西平移（东向分量 −2.3 km）。这一点没有单独验证。最终目录经过深度先验的定位和双差重定位，回到 Pang 附近（0.95 km）。
4. **Kaikōura 的偏移门槛衡量的是"与哪个框架一致"，不是精度。** 参考目录之间就相差 1.3–2.5 km：最终目录离 GeoNet 0.37 km，离 Chamberlain（三维模型的框架）2.51 km，离 Tan 1.82 km。Agent 的通用柱定位离三个参考都在 1.2–1.5 km 之间。以最终目录为标尺、1 km 为门槛，在 Kaikōura 上要求的是与 GeoNet 和最终目录这一侧的框架一致；按 Chamberlain 的框架，最终目录自己也不通过。

## 由此改动

- **知识 skill（`symptoms/not_visible.md`，不含案例名）：** 新增"水平框架"一节，内容是：
  - 没有台站校正的一维定位可能使整批震中平移 1–3 km；
  - 用于全区的区域模型，若含只在部分台站下存在的层（盆地充填），会造成同样的平移；
  - 台站校正每个震相去均值，校正后再比较；
  - 双差重定位会改变绝对框架，接受前要与绝对定位比较；
  - 报告参考框架的不确定度。
- **设计文档：** §11 第 13 条；大纲 §4.3 第 6 条改写。
- **评分口径（待决定）：** 水平偏移门槛固定为 1 km，而 Kaikōura 参考目录之间的框架差超过 1 km（Magna 的 Pang、UUSS 与最终目录也各差约 1 km）。可选做法：门槛取 max(1 km, 参考目录之间框架差的中位数)，或者在这两个案例上把水平偏移改为只报告。这一项先记录，不改评分。
