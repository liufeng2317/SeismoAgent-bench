## 1. 问题

> 能否把地震学家判断"目录对不对"的经验，写成不依赖参考答案的自动检验（checker）和知识，交给通用 Agent，使它从连续波形构建出更接近高精度目录的地震目录？效果多大，边界在哪里？

## 4. 评估

- **精度标准：** 已发表的高精度目录和官方目录，每个目录只承担它能支撑的角色（检测、绝对定位、相对结构、震级），震级以官方目录为准。
- **可达结果：** 同一数据上由工具加专家经验（human-in-loop）得到的目录，用于计算差距弥合率。
- **可信目录标准：** 真实性、时间、空间、强度四个维度，判据、算法和门槛见[计划 A §4.2](./00_A_Research_Plan_Benchmark.md)；完整性单独报告。
- **高精度：** 按[计划 B §4.1](./00_B_Research_Plan_Checker.md) 逐维度判断。
- **checker 审计：** 评分端在提交的产品上重跑 checker，核对报告和每个报警的处置。

## 5. 假设、度量和判定规则

| 编号 | 假设 | 比较 | 主要度量 | 判定为支持的条件 |
|---|---|---|---|---|
| H-B1 | checker 的报警可靠 | 可达结果（应当干净）；合成数据植入错误 | 每个案例的误报数；植入错误的检出 | 可达结果上平均每个案例 ≤ 1 个报警，且每类植入的可检测错误都被对应检查报出 |
| H-B2 | S3 消除了 Agent 自身数据能看到的错误 | S3 对 S1 | 可检测错误的发生次数（震级单位和响应、深度堆积、网格边界、重复事件） | S3 的 12 次运行中这类错误的次数少于 S1 的 12 次运行 |
| H-B3 | S3 弥合了差距 | S3 对 S1，按案例配对 | ①不通过的可信标准判据数；②各维度的差距弥合率 | 至少 4 个案例中 S3 的判据数少于 S1，且差别大于同条件两次重复之间的差别 |
| H-B4 | 自身数据看不到的误差，S3 只在知识提供可用资料时改善 | S3 对 S1 的时间和深度偏差 | 发震时刻偏差、深度偏差的绝对值 | 描述性报告，不作支持或否定的判定 |
| H-B5 | 多数报警得到真修复 | S3（及 S2c）的处置记录 | 报警数；修复、给出理由、表面修复、证据不足的比例 | 真修复加有证据的理由占多数（> 50 %） |

**预期方向**（依据预实验，见进度记录）：H-B1、H-B2 支持；H-B3 在可检测错误多的案例上支持，在速度模型误差为主的案例上不明显；H-B4 中时间和深度偏差多数不改善。

## 6. 分析计划

- **分析单位：** 一次运行；同一案例的 S1 和 S3 配对比较。
- **统计：** 每个配置只有 2 次运行，以描述为主：逐案例报告数值和变化方向；跨案例用符号检验（六个案例中改善的个数）；同条件两次重复的差别作为噪声的尺度，小于它的差别记为"无差别"。
- **分组报告：** checker 和知识的规则都在这六个案例上总结。每个结果都按"规则来源于该案例 / 不来源于该案例"分开报告，每条规则的来源案例在冻结时列表登记。
- **所有运行都报告，不挑选。** 主分析之外的分析标为探索性。

## 7. 排除规则

| 情况 | 处理 |
|---|---|
| 提供方限额、宕机等外部原因中断 | 标为 `EXCLUDED`，重跑，不计入 |
| 运行框架的缺陷导致中断 | 同上，并记录缺陷和修复 |
| Agent 自身原因未完成（超时、放弃、产品不符合约定） | 计入，记为失败运行 |
| 泄漏扫描命中扣留产品 | 报告，不进主分析 |
| 共享环境被改动（`environment_integrity`） | 报告，不进主分析 |
| 访问了待审的网址或路径 | 人工核对后决定，结论记入偏离记录 |
